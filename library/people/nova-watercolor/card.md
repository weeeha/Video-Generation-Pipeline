# Nova — watercolor incarnation

**One-line:** style variant of [Nova](../nova/card.md) for watercolor-storybook projects —
same person, repainted casting.

Same canonical description as Nova's card, with the render style swapped: *hand-painted
watercolor storybook illustration, soft translucent washes, visible paper grain,
brush-textured edges, muted rose-and-slate palette with faded gold accents.*

description; look lives in the refs.
