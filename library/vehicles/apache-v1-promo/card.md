# Apache V1 promo reference pack

## Purpose

Identity and material references for an honest promotional visualization of the
implemented VR Game Things Puzzle AH-64 Apache vertical slice.

## Reference order

1. `01-apache-studio.png` — finished hero model, materials, circular platform,
   and dark studio presentation.
2. `02-apache-exploded.png` — prepared mechanical-system structure. This image
   documents source organization; it does not mean all visible systems are
   playable in V1.
3. `03-apache-assembled.png` — assembled prototype proportions and simplified
   Quest geometry.

## Canonical prompt identity

The exact tabletop AH-64 Apache model shown in Images 1-3, presented as a
realistic VR engineering puzzle inside a quiet dark blue-gray workshop. Preserve
its silhouette, single main rotor, single tail rotor, cockpit, landing gear,
sensor nose, stub wings, and restrained military materials.

Only three pieces are playable in the current vertical slice:

- cockpit;
- main rotor;
- tail rotor.

All other systems remain connected to the base model. The model stays on its
presentation platform and never enters combat or flight.

## Truth boundary

Do not add or imply extra playable pieces, extra rotors, combat, enemies,
flight, destruction, controller-free hand tracking, multiplayer, painting,
commerce, or another playable vehicle. Do not generate product text, logos, or
watermarks inside the cinematic footage.
